# Release operations

This directory contains operational checklists and reference material used during the release process. Contents are public but intended for maintainers.

## Files

- `provenance.md` — Canonical maintainer identity, signature rules, and the
  immutable v1.15 history decision.
- `secrets.md` — Names-only inventory of CI/CD secrets. No secret values appear here or in any tracked file. Values are managed via GitHub Actions secrets.
