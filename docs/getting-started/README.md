# Getting Started

Start here if you are new to ATB.

## First 5 Minutes

```bash
pip install atb
atb init
atb view
```

Then verify integrity:

```bash
atb verify
```

## Install Options

- Python CLI package: `pip install atb`
- Go CLI: `go install github.com/pcguest/atb/cmd/atb@latest`
- TypeScript SDK: `npm install @pcguest/atb-sdk`
