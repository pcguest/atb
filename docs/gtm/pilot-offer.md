# Pilot Offer

The right pilot for ATB is narrow. Do not sell a broad platform evaluation.

## Positioning

Offer a paid pilot when all three are true:

1. there is a live workflow this quarter
2. local control or vendor-independent review matters
3. a portable evidence artefact would remove a real blocker

If any of those are missing, do not force a pilot.

## Pilot Shape

Default scope:

- one workflow
- one integration path
- one review output
- direct founder support

Example scope:

- capture one AI workflow into a local bundle
- verify the bundle locally
- review it in the local viewer with masking enabled
- produce either an incident pack, a customer handoff artefact, or an internal audit/privacy export

## Success Criteria

The pilot succeeds if the buyer can do one of these reliably:

- review a sensitive AI incident without default external trace storage
- hand a customer or internal stakeholder a portable artefact they can verify independently
- produce a deterministic evidence pack without rebuilding it by hand

## Disqualifiers

Do not run the pilot if the buyer mainly wants:

- prompt management
- eval tooling
- collaborative hosted workspaces
- enterprise admin controls

Those are not the product ATB ships today.
