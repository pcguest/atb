1. After `make build`, put the clone directory first on `PATH` (or invoke `./atb`) so `examples/quickstart/run.sh` does not pick up an older `go install` binary. The script documents `ATB_BIN` but README does not.
2. Evaluate unpublished SHA behaviour from the source checkout, not PyPI/npm `@latest` (quickstart already warns registries lag the source tag). Installed Python/TS from this tree.
3. Local Docker image build requires `--build-arg ATB_VERSION=vX.Y.Z`. Used `v1.15.4` (binary version), never `v1.16.0`.
4. Colima on macOS may not bind-mount `/tmp`; a home-directory path was used for `docker run -v` verify, then deleted.
5. `atb verify` without `--profile` may **infer** a profile (here `rag_answer`) and overall-FAIL while the hash chain is valid. Quickstart says use explicit `--profile` for a stable first-run result; `examples/go/README.md` does not.

7. Incident-demo opened with `--profile atb.profile.privileged_tool_action` as in `docs/investigate/incidents.md`. That profile does not pass on this denied/error session; Incident coverage 46% / Trust “Low coverage” is consistent with CLI, not a View bug.
8. Homebrew Node 25 and Python 3.14 were used despite the support matrix (Node 22, Python 3.9–3.12). They worked for this journey.
