## Mechanisms actually present (shipped `/view`)

Absence is recorded. It is not a freeze defect by itself.

| Mechanism | Present on shipped investigation View? | Where / fact |
| --- | --- | --- |
| Paginated raw events API | **yes** | `GET /api/v1/bundle/events` default 200, max 1000. `useBundleEventsQuery` page size 200 + “Load more evidence” |
| Lazy fetch: raw events | **yes** | `useBundleEventsQuery(integrityValid && surface === "evidence")` |
| Lazy fetch: graph JSON | **no** | The shipped Relationships surface derives its graph client-side from already-fetched relationship rows; `useBundleGraphQuery` is unused by `/view`. |
| Opt-in graph panel | **yes** | Relationships `<details>` / `graphOpen`. Copy: “Optional graph of the same rows. Shared identifiers, not causation.” |
| Timeline virtualisation | **no** | `page.tsx` maps every `timelineQuery.data.events` to `<li>`. Legacy `TraceTimeline.tsx` uses `react-window` `FixedSizeList` and is **not** imported by `/view` |
| Session-list virtualisation | **yes**, other route | `SessionList.tsx` `FixedSizeList` on `/sessions`, not investigation Timeline |
| Investigation timeline / context / relationships pagination | **no** | Full arrays. Timeline/context/relationships/findings queries enable as soon as `integrity_valid`, including while Incident is showing |
| Bounded graph node cap | **no** | `handleBundleGraph` emits one node + sequence edge per record; `TraceGraph` maps all into React Flow |
| Memoisation | **partial** | `useMemo` on flattened evidence pages, inspector overlay, TraceGraph nodes/edges, CommandPalette filters. Timeline/Finding rows are not `React.memo` |
| `next/dynamic` / `React.lazy` | **not on investigation surfaces** | `TrustScoreCard` dynamically imports `TrustScoreRadial`; that card is not mounted on shipped `/view` |
| Lazy inspector | **yes** | One selected event; `JSON.stringify` in `max-h-[380px]` overflow `<pre>`; no truncation |
| Context numeric cap | **no** | `contextlineage` package comment says “bounded”; `Build` returns every unit/operation |
| Capture-side memory bounds | **yes**, not View | Bundle load 512 MiB / 1_000_000 records; proxy body/in-flight caps. View pretty-prints the selected event as stored |
| Evidence refetch while open | **yes** | `liveEventsRefetchIntervalMs = 5000` |
| Graph refetch while Relationships open | **no** | `/view` does not request graph JSON. |

Viewer spec (`docs/specification/viewer.md`) still lists paginated API, timeline virtualization, and lazy detail as required for “10k+ events smoothly”. Shipped v1.16 investigation View has pagination only on Evidence, virtualisation only on unused/legacy surfaces, and lazy detail in the inspector. Recorded as debt, not as a silent claim.

## Surface assessment

### Initial load

Incident paints a bounded summary plus three finding cards. HTML 10 KiB, overview sub-millisecond after warmup. Prefetch of unpaginated timeline/relationships is the cost: ~1.1 MiB (2k) / ~5.6 MiB (10k) JSON parse on the client before those lists mount. **Usable** at 2k. 10k prefetch is heavy but did not block Incident in Cypress.

### Timeline

Unvirtualised full list. 2001 rows: 5 s full investigation flow. 10001 rows: mounts; no virtualisation. **Not a realistic-use blocker** at 2k. Spec 10k smoothness is unmet → debt.

### Findings

Six cards. Incident slices to three. **Usable.** Cardinality is session-index flags, not O(n) events.

### Relationships

Unvirtualised list. 5250 dense rows at 2k still completed in the 5 s Cypress pass. 26250 rows at 10k is fixture-pathological and the main jank risk; Cypress still finished including this list. Typical sparse bindings will be far smaller.

### Graph

Unbounded React Flow derived from the already-fetched relationship rows. Opt-in `<details>` controls rendering, not a separate graph request. 2001 nodes opened inside the 5 s 2k pass. 10001 nodes opened inside the 10k pass (no crash). **No node cap.** Debt, not a default-path freeze at realistic size.

### Context expansion

All unit cards rendered (70 at 2k, 350 at 10k). No collapse/virtualisation. `policy-handbook` visible. Operations were 0 on these fixtures (generator branch overlap); units still stress the map. **Usable.**

### Raw evidence + large JSON

Only paginated investigation surface. First page 200. Load more appended a second page in the 2k Cypress pass. Inspector pretty-prints the selected event in a scrollable `<pre>`; 32 KiB / 200 KiB completions are in the 2k bundle; last-page API 347 KiB in 1.3 ms. No JSON tree virtualisation, no truncation. 32 MiB intercept bodies were **not** opened in the inspector → debt, not a PTA/incident FAIL.

### Memory

`atb view` RSS stayed tens of MiB (22–63 MiB observed), not hundreds. After large JSON responses were dropped, 10k RSS returned to ~30 MiB. No leak signal in this window. No JS heap sample (Electron `performance.memory` not recorded on the passing run).

### Interaction responsiveness

2k: full auditor path in 5 s including graph and palette. 10k: all surfaces reachable; unbounded lists are the debt. Small-bundle live interaction on this SHA is already PASS in `V116_LIVE_INVESTIGATION_REPORT.md`.

## Documented debt (non-blocking)

1. Shipped investigation **Timeline is not virtualised**; `react-window` lives on unused `TraceTimeline` and on `/sessions`.
2. **Timeline / context / relationships / findings APIs are unpaginated.** View **prefetches** them as soon as integrity is valid, including on Incident.
3. **Graph is unbounded** (one React Flow node per event), derived from relationship rows and rendered only after `<details>` opens. Viewer spec “10k+ smoothly” is not met.
4. **Relationships list is unvirtualised.** A dense shared-id bundle can emit tens of thousands of rows (26250 in the 10k stress fixture).
5. **Evidence list** is paginated (200) but **not virtualised**. Inspector `JSON.stringify` has no truncation; 32 MiB capture bodies were not opened here. Evidence query **refetches every 5 s** while the surface is open.
6. `contextlineage.Build` has no numeric cap despite the “bounded investigation view” comment.
7. Do not advertise 10k-event UI smoothness for shipped `/view`.

None of these made realistic evidence unusable in this run.
