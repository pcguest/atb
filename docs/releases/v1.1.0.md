# ATB v1.1.0
**Release Date:** 2026-03-12  
**Tag:** `v1.1.0`  
**Security Sign-Off:** `APPROVED FOR GOLD RELEASE` (see `docs/security/gold-signoff.md`)  
**Release Validation:** GitHub checks passing across security gates, golden tests, and macOS/Linux/Windows CI

ATB v1.1.0 makes the product easier to evaluate in private AI environments. The release adds a local trust dashboard, tighter privacy reveal controls, and cleaner release hygiene for teams that need a verifiable record without default hosted trace storage.

## Why It Matters

- Security-minded AI teams can inspect and verify traces locally after an incident or model failure.
- Consultancies can hand clients a portable audit artefact instead of reconstructed notes.
- Privacy-sensitive enterprise builders get better controls around masked data and reveal auditability.

## What Shipped

### Local Review Workflow

- Local dashboard for timeline, graph, inspector, and role-based review views
- Trust score and recent-event polling for quick bundle inspection
- Accessibility baseline in place for the embedded review UI

### Privacy Controls

- Token-based auth on `/privacy/reveal` via `X-ATB-Viewer-Token`
- Rate limiting at 10 requests per minute per token
- Hash-chained audit logging for every privacy reveal
- Configurable PII masking via `docs/compliance/pii-fields.json`

### Release and Developer Hygiene

- OpenAPI generation via `atb doc gen-openapi`
- Stronger release gates with `make hygiene-full`, `make test-embed`, and `make gate-gold-release`
- Reproducible Docker test path via `make test-docker`
- Automated dependency and security scanning in CI

## Install or Upgrade

```bash
git clone https://github.com/pcguest/atb.git
cd atb
git checkout v1.1.0
go build -o atb ./cmd/atb
```

To try the local review flow:

```bash
./atb init
./atb append agent.run --data='{"agent":"support-triage"}'
./atb view --ui-experimental
```
