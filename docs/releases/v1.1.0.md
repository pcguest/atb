# ATB v1.1.0: Trust Dashboard - Gold Release
**Release Date:** 2026-03-12  
**Tag:** `v1.1.0`  
**Previous Version:** v1.0.3  
**Security Sign-Off:** `APPROVED FOR GOLD RELEASE` (see `docs/security/gold-signoff.md`)
**Release Validation:** Current GitHub release checks passing across security gates, golden test, and macOS/Linux/Windows CI

## What's New

### Trust Dashboard UI
- **Enterprise-grade React dashboard** (Next.js 14, shadcn/ui, Recharts)
- **Role-based views:** Engineer (debug), Auditor (compliance), Executive (summary)
- **Trust Score:** 0-100 algorithmic integrity metric
- **Real-time polling:** New blocks appear within 5 seconds
- **Accessibility:** WCAG 2.1 AA compliant (Lighthouse A11y: 100/100)

### Security Enhancements
- **Auth on /privacy/reveal:** Token-based (`X-ATB-Viewer-Token`)
- **Rate limiting:** 10 requests/minute per token
- **Hash-chained audit:** All privacy reveals logged to `bundle.atb`
- **CSP headers:** Strict Content-Security-Policy on embedded UI
- **PII masking:** Configurable via `docs/compliance/pii-fields.json`
- **Dependency scanning:** Automated govulncheck + npm audit in CI

### Developer Experience
- **Main-only workflow:** No long-lived feature branches
- **Hygiene gates:** `make hygiene-full`, `make test-embed`, `make gate-gold-release`
- **Docker test env:** Reproducible E2E testing via `make test-docker`
- **OpenAPI generation:** `atb doc gen-openapi` command

## Installation

```bash
# Build from source
git clone https://github.com/pcguest/atb.git
cd atb
git checkout v1.1.0
go build -o atb ./cmd/atb

# Verify build
./atb version
# Output: atb version v1.1.0

# Run dashboard
./atb init
./atb append --type=milestone --data='{"name":"First Block"}'
./atb view --ui-experimental
```

## Testing

```bash
# Run all tests
make test-all

# Run E2E tests (Docker recommended for stability)
make test-docker

# Run security scans
make security-scan
```
