## 1. `.atb` compatibility — PASS

Mortise ingest takes **raw bundle bytes** (`Content-Type: application/octet-stream` → `POST /ingest`), not a derived archive. ATB CLI (`incident export --mortise-endpoint`, `intercept --mortise`, `compliance pack --mortise-endpoint`) and Go `internal/mortise.HTTPClient.SendBundle` post the `.atb` file unchanged.

`pkg/custody.Evaluate` / `LoadBundle` parse NDJSON via `bundle.LoadReader` and run ATB verify. `HeadHash` is the last record hash (chain head), not a second hash of the file.

`git diff v1.14.3..HEAD -- internal/hash/hash.go internal/canonicalize` is empty of production hashing changes (canonicalize gained coverage tests only). Bundle load gained resource limits (`MaxBundleSizeBytes` / `MaxBundleRecords`); that does not change canonical hash input. Fixtures on this SHA still verify (`chain_valid=true`, `pass=true`).

Mortise `internal/verifyingest` gates **integrity only** (`GateResult.ChainValid`); intact-but-incomplete bundles are admitted. That matches ATB: profile FAIL is not a hash-chain FAIL.
