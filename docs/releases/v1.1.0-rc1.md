# ATB v1.1.0-rc1 Release Notes
**Release Date:** 2026-03-12  
**Tag:** `v1.1.0-rc1`  
**Commit:** `6315310b0b880b01e9f91513516058427169b92d`

## What's New

### Trust Dashboard (UI)
- **Embedded React dashboard** for local review
- **Role-based views:** Engineer (debug), Auditor (compliance), Executive (summary)
- **Real-time updates:** 5s polling for new blocks
- **Trust Score:** 0-100 algorithmic integrity metric
- **Interactive visualizations:** Recharts-based hash chain graph
- **Accessibility:** WCAG 2.1 AA compliant

### Security Enhancements
- **Auth on /privacy/reveal:** Token-based (`X-ATB-Viewer-Token` header)
- **Rate limiting:** 10 requests/minute per token
- **Hash-chained audit:** All privacy reveals logged to `bundle.atb`
- **CSP headers:** Strict Content-Security-Policy on embedded UI
- **PII masking:** Bundled defaults with `ATB_PII_FIELDS_PATH` override support

### Developer Experience
- **Main-only workflow:** No long-lived feature branches
- **Hygiene gates:** `make hygiene-quick`, `make hygiene-full`, `make test-embed`
- **OpenAPI generation:** `atb doc gen-openapi` command
- **CI/CD:** GitHub Actions for security scans, test coverage

## Installation

```bash
# Build from source
git checkout v1.1.0-rc1
go build -o atb ./cmd/atb

# Verify build
./atb version

# Run dashboard
./atb init
./atb append milestone --data='{"name":"First Block"}'
./atb view --ui-experimental
```

## Testing

```bash
# Run all tests
make hygiene-full

# Run E2E tests (UI)
cd web && npm run test:e2e

# Run security scans
make security-scan
```
