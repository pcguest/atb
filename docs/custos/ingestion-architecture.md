# Custos ingestion architecture (moved)

The supported Custos runtime is maintained in the separate
[Custos repository](https://github.com/pcguest/custos-product). See its
[end-to-end guide](https://github.com/pcguest/custos-product/blob/main/docs/e2e-atb-custos.md)
and [capability boundary](https://github.com/pcguest/custos-product/blob/main/docs/capability-boundary.md).

ATB retains only the local evidence contract and the in-repo reference scaffold
used for compatibility testing.
