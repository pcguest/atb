# Early User DM Template

Use this for post-launch outreach to first users.

## Short DM

Hi {{name}} — I noticed you checked out ATB.

I’m the founder and I’d value 2 minutes of blunt feedback. ATB is for tamper-evident AI workflow traces (local-first).

Could you share:

1. What was missing for your use case?
2. What felt confusing or slow?
3. What would make this worth paying for?

If useful, I can help you set up your first trace in 10 minutes.

## Follow-up Questions

- Which stack are you using (LangChain, custom agents, other)?
- Is your main pain debugging, compliance, or collaboration?
- Would local viewer + secure share links solve your immediate need?
- If you stopped using it, what caused drop-off?
